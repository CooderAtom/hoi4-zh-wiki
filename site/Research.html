科研用于解锁科技。科技可以解锁新的单位、装备或建筑，也可以提升现有单位、装备和建筑的性能。

科技

陆军
  • 步兵科技：改善步兵武器与装备的科技，可解锁或改进摩托化与机械化单位以及特种部队（海军陆战队、山地兵和伞兵）。
  • 火炮科技：解锁并改进所有类型火炮的科技，包括反坦克炮、防空炮和火箭炮。
  • 支援连科技：解锁并改进所有类型支援连的科技：工兵连、侦察连、军事警察连、维修连、野战医院连、后勤连和通信连。
  • 装甲科技（不同于未拥有绝不后退）：解锁所有类型与型号坦克的科技，从轻型到超重型底盘，以及其变体：坦克歼击车、自行火炮和自行防空炮。
海军
  • 海军科技（不同于未拥有全民持枪）：解锁或改进所有类型舰船单位的科技：驱逐舰、轻型与重型巡洋舰、战列巡洋舰、战列舰、航空母舰和潜艇。
  • Naval support科技：在全民持枪下，海军支援科研树包含所有并非直接衍生自舰体的科技。这些科技大多是新型或改进型的海军武器。
空军
  • 空军科技（不同于未拥有以血盟誓）：解锁或改进所有类型机体的科技：轻型、中型或重型，以及它们的喷气推进版本。
工业
  • Engineering科技：汇总所有与电子工程（计算机、无线电、密码学）、火箭和原子研究相关的科技。
  • Industry科技：汇集所有能提升各类工厂生产效率与产量、增加资源开采，以及解锁并改进合成炼油厂的技术。
特殊项目
  • 特殊项目：通过完成特定特殊项目直接解锁的所有科技。

科研槽

将科研槽分配给某项科技并持续所需天数，即可解锁该科技。

部分国家有指定的基础科研槽数量，而其他欧洲国家默认为3个，非欧洲国家默认为2个。除基础科研槽外，国家还可以通过其国策树解锁额外科研槽（视国家不同为1~3个）。对大多数国家而言，这些焦点分属不同分支，一局游戏中无法全部完成。其中一些焦点需要满足条件，例如拥有足够数量的工厂（通常为50个以上），而英联邦国家还必须完全独立，才能最大化其可用科研槽。

科研速度

基础科研成本指研究某项特定科技所需的时间。实际上，由于会施加不同的科研修正，该成本每次往往都会变化（或有利或不利）。

科研速度修正以加法叠加到科研速度上（而不是从科研成本中扣减）。例如，基础成本 110 天、科研速度加成 15% 时，所需时间为：

\lceil \frac 1101+15\%\rceil =96 天。

「节省天数」会从修正后的预计天数中扣除。因此，「节省天数」也受相同科研速度修正的加成（或惩罚）。

总科研加成每天都会计算并更新。因此，科研速度的变化（有限次加成除外）会作用于所有进行中的科研。

科研速度不能低于默认速度的 10%。[3]

科研修正

难度

根据游戏难度设置，玩家会获得科研速度加成或惩罚，具体如下：

  • 平民：+15% 加成
  • 新兵：+7% 加成
  • 普通：无加成或惩罚
  • 老兵：–15% 惩罚
  • 精英：–30% 惩罚

贸易法令

贸易法令也能提高科研速度。贸易越开放，减免越多，如下所示。

  • 自由贸易：+10% 加成
  • 出口重点：+5% 加成
  • 有限出口：+1% 加成

有限次加成

有限次加成由国策提供。一旦可用，当某个科研槽被指派研究适用的科技时，有限次科研加成即被激活。激活后，即使重新指派该槽位，有限次加成仍与该科技绑定。不过，游戏给予 3[4] 天的宽限期，以便用同一槽位将该加成切换到另一项适用的科技。

有限次加成还可充当超前加成，按标明的数值降低超前惩罚。

部分海军科技和海军支援科技允许玩家花费海军经验，为其获得一次性科研速度加成。这些加成会叠加在与其一同消耗的既有一次性加成之上。

装备许可生产

当他国许可生产装备时，研究该装备可获得 20% 的速度加成。[5] 对于使用设计的装备，例如坦克 (带有 )、舰船 (带有 ) 和飞机 (带有 )，该加成仅适用于底盘、舰体和机体科技，不适用于被许可设计任何部件的模块科技。

科技共享

当一个国家加入研究集团时，集团内每个已解锁该科技的其他国家都会为其提供研究速度加成，最高可达50%。[6]科技共享加成的作用方式与有限次加成的相同：一旦生效，加成即锁定在该科技上；该国科技共享状况的变化只会反映在未来的研究中。附属国从科技共享中获得的收益会因自治度等级不同而减少。

其他科研加成来源

各类国家精神、政治顾问和设计公司在任职期间可持续提升适用科技的研究速度。

拥有反抗暴政后，可指派军工组织进行研究，提供科研速度加成，但每天消耗政治点数。

超前惩罚

所有科技都附有一个成为当前科技的日期。提前研究它们会以降低科研速度为代价。每提前一年会增加 200% 的超前（AOT）惩罚。[7] 来自国策的超前加成可降低该惩罚修正。对于超前研究，游戏内提示框会使用下方公式显示预计完成时间。

某项科技在其成为当前科技之日前 : T 年开始研究，基础科研成本为 : N 天，总科研加成为 : B %，则完成需要 : 365(T+(1)/(AOT))(1-e^-(AOT· N)/(365)(1)/(1+B\%)) 天，其中 : AOT = 2 表示不扣除任何来自国策的惩罚减免。这里假定研究开始时的速度高于最低速度，且在科技成为当前科技之前完成。该结果还存在微小的近似误差（游戏内基本无法察觉）。该公式通过求解下列关于 : t 的积分方程得出（以天计）：

: N=365∫_0^t \frac1+B\%AOT·(T-(x)/(365))+1 dx

: (N)/(365)(1)/(1+B\%)=∫_0^t \frac1AOT(T-(x)/(365))+1 dx
: (N)/(365)(1)/(1+B\%)= \frac\ln(AOT· T+1) - \ln(AOT·(T-(t)/(365))+1)AOT
: (AOT · N)/(365)(1)/(1+B\%)= \ln(\fracAOT· T+1 AOT·(T-(t)/(365))+1)
: e^-(AOT · N)/(365)(1)/(1+B\%)= \frac AOT·(T-(t)/(365))+1 AOT· T+1
: (T + (1)/(AOT)) e^-(AOT · N)/(365)(1)/(1+B\%)= T-(t)/(365)+(1)/(AOT)
: (t)/(365) = T+(1)/(AOT) - (T + (1)/(AOT)) e^-(AOT · N)/(365)(1)/(1+B\%)
: t = 365 (T + (1)/(AOT)) (1 - e^-(AOT · N)/(365)(1)/(1+B\%))

如果部分研究不处于惩罚状态（即上方方程中的 : t>365T），则在 AOT 为 2 时的预计完成时间为 : 365(T+(N)/(365(1+B\%))-(\ln(2T+1))/( 2 )) 天。

例如，在某项科技成为当前科技的整整一年前，该科技的科研速度会乘以 : 1/3 的系数。由于科研速度每天都会重新计算，研究进行期间速度惩罚会逐渐下降。半年后，惩罚降至 : 1/2。常规科研速度修正为线性叠加，因此全国范围的常规科研加成并不能缓解超前惩罚。如果游戏内提示框显示 50% 的超前加成已生效，则会从超前惩罚中减去 0.5。于是，在提前 1 年时，科研速度会乘以 : (1)/((2· 1-50\%)+1)=2/5，而不是没有加成时的 : 1/3；同样，在提前半年时，超前惩罚会降至 : (1)/((2· 0.5-50\%)+1)=2/3，而没有加成时为 : 1/2。

以下是一段 Python 脚本，用于根据基础成本、加成和超前惩罚计算研究一项科技所需的时间。

res_perc = 0.0
time = 0
base = 170      # Base Cost
bonus = 0.34    # Research Speed Bonus
aot = 0.47      # Ahead-of-time penalty (not years ahead)
base /= 1+bonus
while res_perc<1:
   res_perc += 1/base/(1+aot)
   aot -= 2/365
   if aot<0: aot = 0
   time += 1
print(time)     # Prints total time needed
