本页面列出了可输入控制台窗口的指令代码。控制台窗口是一个特殊的调试窗口，在非铁人模式下按 ^ 、° 或波浪号（~）即可打开（按键因键盘布局而异）。按上、下方向键可翻阅此前执行过的指令。许多指令可通过重复输入来关闭，但有时需要重新加载存档或退出游戏。请注意，许多指令会随每个 DLC 的推出而出现或消失，因此其中一些可能无法使用。模组也可能为游戏引入指令，更常见的是引入标签，以增强其玩法。

另需注意，按设计，指令在铁人模式游戏中可能无法使用。

指令列表

按 Shift+2、§、~、\、`、"、º、^ 或 ALT+2+1，或 Shift+3 可打开控制台（按键因键盘布局而异）

内部 ID

另见：国家

控制台指令使用内部 ID，可通过多种不同方式获取。

查看内部 ID 的一个简便方法是调试模式。debug 作为控制台指令可开启调试模式，将鼠标悬停在某些数据库条目上时可提供相关信息，例如国策、国家精神（以及法令、设计商等其他理念）或科技；悬停在一个省份上时，还可获取该州与省份的 ID，以及其所属国家的三字母国家标签。请注意，在进行模组制作时，该控制台指令并不能实现启动选项的全部功能，无法作为其替代。

如果无法做到，使用本地化文件是另一种方法。为此，请先找到游戏所在文件夹，然后进入 /Hearts of Iron IV/localisation/english/ 文件夹。其中的每个文件都包含本地化键，并为其分配了实际在游戏中显示的值。使用非默认的文本编辑器还可以使用“在文件中搜索”功能（例如 Notepad++、Sublime Text 或 Visual Studio Code 中），从而同时搜索每一个本地化文件，以找到指定的值。

消歧义

在本文中，指令内使用了 3 种括号：

  • 像 instantconstruction(ic) 这样的圆括号用于表示别名，即控制台指令的替代名称。在此例中，使用 ic 或 instantconstruction 在游戏中的效果相同。
  • 像 fow [省份 ID] 这样的方括号表示 可选 参数。在此例中，fow 和 fow 1234 都能生效，但效果可能不同。
  • 像 event [<事件 ID>] 这样方括号与尖括号组合使用，表示 必填 参数。在此例中，event generic.1 会生效，但 event 不会。

术语表

MIO 是 Military Industrial Organizations（军事工业组织）的缩写

实用指令

指令 效果 示例/备注
help [命令名称] 打印所有控制台指令或某条指令的说明。
tag [<国家标签>] 切换玩家所控制的国家。
event [<事件 id>] [目标国家标签] 执行一个事件 事件页面 可用于告知事件的 ID。如果该事件带有 trigger = { ... } 块，它会说明哪些触发条件已满足、哪些未满足。
finish_decision [<决议 id>] 或 "all" 立即完成限时任务。
add_ideas [<理念名称>] 为国家添加理念，ID 为 <id>。也可用于替换法令。
remove_ideas [<理念名称>] 移除国家理念。
energy_ratio (er) [<比率>] 为不消耗煤炭的工厂设置能源比率，取值 0 到 1。
FI [数值} 增加阵营倡议 FI 5 增加 5 点阵营倡议
mastery [<精通数量>], [路线名称] 给予学说精通度，可全局给予或给予特定分支。
gain_xp [<数值>] 为选中的领袖/将领/海军上将增加经验 gain_xp 100000（等级上限为 9）
gain_xp [<特质>] 为选中的领袖/将领/海军上将添加 gainable 特质 即：gain_xp seawolf

备注 To make it work with new, generic created Admirals:
1. Open 'Documents\Paradox Interactive\Hearts of Iron IV\settings.txt' with a text editor and change "save_as_binary=yes" to "save_as_binary=no".
