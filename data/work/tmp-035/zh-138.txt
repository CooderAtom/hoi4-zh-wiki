FROM
declare_war_on = { target = FROM type = annex_everything } FROM = { load_oob = defend_ourselves }
可以无限串联为 FROM.FROM。用于指向该语句块固有的各种硬编码作用域，通常是除 ROOT 之外的第二作用域。例如：在事件中，它指发送事件的国家（即若该事件是通过效果触发的，则为触发它的 ROOT 作用域）。在有目标决议或外交脚本触发器中，它指被选为目标的作用域。

add_dynamic_modifier
⟦0⟧ 修正的名称。⟦1⟧ 若指定，动态修正将被限定到该作用域。可选。⟦2⟧ 经过 x 天后，这些修正将被移除。可选。

向指定作用域添加一个动态修正（默认作用域为 ROOT）。它每天更新一次，除非通过 force_update_dynamic_modifier 效果强制提前更新。
示例可在⟦0⟧中找到。动态修正中任何使用变量的修正项都不会显示在此效果的工具提示中，而设为静态值的修正项则会显示。支持州、国家、角色和特殊项目作用域。
